# 🐬 Aquassim 🪼- Visualize natural selection
## Description 🔍📃
**Aquassim** is a simulator made entirely in **pure C** to simulate aqua creatures in the sea. It generates **1000** entities \
with random shapes and behaviors, then use a selection algorithm to make creatures attributes evolve in order \
to gain efficiency in their movements.
## Comimg features
> * Complete physic engine
> * Selection algorithm
> * User-friendly interface
